## 2. 呈现策略：问题替换、答案叠加（关键设计决策）

- 用户问题是纯文本 → 翻译完成后直接替换气泡文字，原字符串留在内存，按钮可来回切 Original / Translation。
- 答案不是纯文本 → 由 PbiRecommendation 把该轮 rawEvents 渲染成结构化内容（最终答复正文、图表卡、表格、SQL 块、季度标签、推荐追问）。只提取可翻译的自然语言正文（finalAssistantText + 多 Agent 的 profileTaskAnswers）送翻，译文作为独立 .translate-panel 挂在原答案卡下方；卡片内的 Original / Translation 只切该译文块自身内容，不动上方图表/表格。
- 理由：整块替换会让图表、表格、SQL 一起消失，用图表可读性换译文不划算。
- 备选方案与代价（用户尚未拍板）：
  1. 只调呈现：译文块嵌进答案卡正文段落处，或折叠原正文只留图表 —— 需解析 PBI 渲染结构，确定性一般；
  2. 真替换正文：给 PbiRecommendation 加“正文覆盖”prop —— 该组件在真实 Chat BI 页面共用，有回归风险，需额外测试。
