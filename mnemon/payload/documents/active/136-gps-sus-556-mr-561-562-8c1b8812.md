## 一、结论：开关是开的，但自动评审没有调度器

`public.ssg_chatbi_question_review_setting`（id=1）实况：`auto_review_enabled=t`、`auto_wrong_timeout=t`、`auto_wrong_failed=t`、`auto_wrong_no_result=t`、`auto_wrong_needs_input=f`、`updated_by=renxp4`、`updated_at=2026-11-14 00:38:07`。规则配置本身无误。

表里还有一列 `auto_wrong_permission=t`，但代码里 **0 处引用**——历史遗留列，不影响任何行为。

`com.lenovo.admin.chatbi` 包下只有两个 `@Scheduled`，且都是 Jira 建单链路，**自动评审本身没有定时任务**：
- `smartop-service/admin/src/main/java/com/lenovo/admin/chatbi/jira/ChatbiFailedQueryJiraScheduler.java:28`
- `smartop-service/admin/src/main/java/com/lenovo/admin/chatbi/jira/ChatbiReviewJiraScheduler.java:27`

自动评审只有两个入口：
1. 页面 Run backfill → `POST /chatbi/events/report/review/backfill`（`ChatbiEventReportController.java:867` → `ChatbiQuestionAutoReviewService.runBackfill`）；`runBackfill` 有前置守卫：开关关着直接抛 `IllegalArgumentException("Turn on Auto review before running a backfill")`（`ChatbiQuestionAutoReviewService.java:91-93`）。
2. 保存规则时顺带跑 `convertLegacyAutoNoPermission`，只把历史 NO_PERMISSION 结论改判 NOT_APPLICABLE，**不做新评审**。

**既有文档 750e10a9 记的「另有每小时兜底任务」与代码不符**，本次核查无任何自动评审 `@Scheduled`。

### 为什么用户截图那轮不进自动评审

用户给的轮次（`apartaledis`，session `d5f1a22f-2a26-447b-b3c0-9d65289ba9c9`，2026-11-17 03:03:57）三个独立原因任一都足以排除：
1. 带 `No LUDP permission`，被硬性排除 —— `ChatbiQuestionAutoReviewMapper.java:92` `AND NOT LUDP_PERMISSION_SQL`；判定见 `ChatbiEventQueryMapper.java:448-453`（回查 `agent.tool_audit_logs` 里 `execute_compiled_query`/`execute_sql` 的 `output_summary` 含 `ludp_permission_denied`）。这类轮次事件表仍记 `status=success`，只看 `failed_step` 永远认不出。
2. `Final result = Success`，失败判错规则不触发。
3. 超时/无结果/反问均不匹配。

### 三项候选动作（用户当时未拍板）

1. 页面 Run backfill（范围 All）→ 消化 136 条失败轮次。
2. 给自动评审加 `@Scheduled`（照 `ChatbiReviewJiraScheduler` 样式，如每 6 小时扫最近 2 天）。
3. 加「LUDP 无权限 → 自动 NOT_APPLICABLE / No permission」规则，消化 37 条。需用户拍板：现口径是注释里写死的「无权限属于授权/环境问题，绝不自动判」。

顺序约束（反了就出事）：先用「已合 !561、未合 !562」的 admin-release 构建并发版 → 发完版再合 !562 → 下次发版带上。顺序反了，刚摘掉的代码会跟着这次发版包上线。

Git 教训（已写进两个 MR 描述）：!562 合并后 `feature/gpssus` 历史闭环，**不能再靠重新 merge `feature/gpssus` 恢复任何东西**——Git 认为已合并、不会带回改动。这类临时摘除/恢复只能走 revert 链。
