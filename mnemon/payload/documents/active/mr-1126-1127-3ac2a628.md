# 回放翻译全量化：整轮替换 + 反问/建议/图表文案覆盖（MR !1126 / !1127）

前序背景见 `b9e951c9-33cb-412e-9af8-853d163a3886`（Teleport 进弹窗标题栏、只翻当前 turn 的版本）。本文记录其后一次范围升级：从「双语对照、只翻当前 turn 正文」改为「整轮替换、覆盖反问卡与图表文案」，并在 master 上重新接入曾于 !1125 被 revert 的入口。

## 需求口径（用户验收标准）

领导提三个问题：①没有原文翻译；②反问没翻译（翻译不全）；③大屏下最后一个问题无法翻译。
用户明确的验收口径是「用户观感上全翻译，而不是代码上全翻译」——即正文区、反问卡、图表卡片里看得见的中文，而不是要求代码层面每处都走翻译。

## 架构：翻译范围收敛到单一文件

新增 `src/components/PbiRecommend/pbiTranslate.ts`，是功能的唯一入口：

```ts
collectPbiTexts(model)              // 从渲染模型里收集所有用户可见文本
applyPbiTranslations(model, map)    // 把译文回填进模型
```

`PbiRecommendation.vue` 只在 `renderModel` 末尾加一行 `applyPbiTranslations(...)`；不传译文时原样返回入参（零拷贝），因此 **Chat BI 实时会话行为完全不变**，改造成本被隔离在回放分支。以后要加可翻字段只改这一个文件，不必在模板里到处找。

配套：`src/views/Setting/reports/history-replay/HistoryChatPanel.vue` 负责收集/提交/存储译文与整轮切回原文；`translateApi.ts` 提供 `translateApi`（master 上原本不存在，随本次一并接入）。

## 翻译范围

| 翻 | 不翻 |
|---|---|
| 最终答复正文、多 Agent 公开答复 | SQL 代码块 |
| 反问卡问题 / header / 选项 label 与说明 / `escalation.reason` | 表格数据行 `data.rows` |
| 建议卡名称 / 理由 / tag | 列 key、字段名 |
| 子任务摘要 | 过程区（流式中间态） |
| 图表标题 / 说明 / 表头 / 视图标签 | URL、任务 id、状态码、数字、期间代码（FY2425Q1、220.1M） |

反问卡此前完全漏翻，是因为收集范围没进入 `profileTaskInputs[].inputs.questions[]`；这一层是"翻译不全"的根因。

## 大屏最后一个问题翻不了的根因

`syncActiveTurn` 原先把视口定位用的视角线固定为 32%，在大屏上这一比例永远落在最前面几轮，于是"当前轮"的跟随目标始终是第一轮。修复添加两条兜底：

- 内容不足一屏（没有滚动空间）时，目标直接定为最后一轮；
- 已经滚到底时，同样取最后一轮。

## HistoryChatPanel 关键实现

- 译文按语言前缀 + turnId 存储：`translations.value[\`${langPrefix()}:${turnId}\`]`，`turnTextMap(turnId)` 取当前语言映射，`visibleTurnMap(turnId)` 在 `isShowingOriginal(turnId)` 时返回 undefined（整轮回退，不做中英并排）。
- `originalTurns: Record<string, boolean>` 只对翻过的轮有意义；标题栏按钮在 Translation / Original 间整体切换。
- `userBubbleText(message)` 先查 `map[original]`，再查 `map[original.trim()]`——提交翻译时问题文本被 trim 过，两形态都试可避免首尾空白导致用户气泡漏译。
- `collectTurnTexts(turnId)` = 该轮 user 问题 + 紧随其后 assistant 渲染模型的 `collectPbiTexts` 结果。
- 切换会话 / 重新发起时清空 `translations`、`originalTurns`、`translatedLabel`、`translateStatus`、`activeTurnId`。
- `result.degraded` 时展示 `result.error` 或 "Part of the text could not be translated; the original is shown for those parts."，未译部分保留原文。
