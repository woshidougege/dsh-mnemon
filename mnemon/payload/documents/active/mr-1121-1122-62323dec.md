# 会话回放翻译改为"全手动"：只翻当前视口那一轮（!1121 / !1122）

`ssg_sales_ops` 前端 `HistoryChatPanel.vue` 的翻译能力第三次迭代。上一版（见文档 `b9e951c9-33cb-412e-9af8-853d163a3886`，MR !1114 / !1115）已把控件 Teleport 进 DetailModal 标题栏并收敛到当前 turn，但仍在打开弹窗/切语言时自动发请求。本次按用户要求彻底改为手动。

## 1. 用户诉求（决定成败的需求原文）

- “感觉设计的不太好啊 我想手动控制翻译 不想每次都翻译呢  可以加一个按钮 翻译当前问题 之类的  吗  你觉得呢？”
- “都要手动翻译啊 用户点了才翻译 不搞自动翻译   翻译按钮也放在最上面不行吗”

约束：**零自动触发**（打开弹窗不翻、选语言不翻、滚动不翻），全流程只有一个请求入口 = 标题栏那个按钮；按钮放标题栏最上层（不是正文区、也不是每轮下方的局部按钮）。

## 2. 交互设计

- 按钮翻的是**当前视口那一轮**：滚动时用 `rows` 的 `getBoundingClientRect().top` 与 `viewTop + viewHeight * 0.32` 比较，取视口上方 1/3 处所属 turn 作为 `activeTurnId`；该轮左侧显示 2px 竖条，作为“按钮会翻哪一轮”的视觉锚点。
- 按钮三态（`translateActionLabel`）：未译 → `Translate`；已译且显示译文 → `Original`；已译且显示原文 → `Translation`；请求中 → `Translating…`（`total > 1` 时 `Translating done/total…`）。
- `translateActionTitle` 把目标问题前 120 字符塞进 `title`，悬停即可确认翻哪一轮，缓解“按钮和内容对不上”的困惑。
- 每轮译文块头部另带 `Original / Translation` 小切换，状态按 turn 独立（`originalTurns[turnId]`），不再全局开关。
- 语言选项改本地写法 `English / 中文 / 日本語 / Español / Custom…`，删掉原 `Original` 选项（下拉只表示目标语言）；切回已翻过的语言直接命中内存缓存，不重发请求。

## 3. 实现要点（`src/views/Setting/reports/history-replay/HistoryChatPanel.vue`）

- `collectTranslationJobs(turnId)`（约 :396-411）：只产出 `user-{questionIndex}` 与 `assistant-{questionIndex+1}` 两个 job，并把答案正文缓存进 `assistantTexts`。
- `isTurnTranslated(turnId)`（约 :413-431）：纯计算、不写缓存 —— 用 `langPrefix()` 拼 key，判断 `translations[`${prefix}:user-${i}`]` / 同形 assistant key 是否 `!== undefined`；空问题视为已译。这是按钮能在“已译/未译”间正确翻转的前提。
- `translateActiveTurn()`（约 :456 起）：未选语言时打开语言菜单并提示 `Pick a language first.`；已译则 `toggleOriginal(turnId)` 翻转，未译才真正发请求；`translating` 期间直接 return，防重复点击。
- 模板：标题栏 `<Teleport defer to="#replay-toolbar-anchor">` 内是语言胶囊 + `.translate-action` 按钮（约 :596-645），按钮带 `is-busy` / `is-flipped` 修饰；正文侧只留 `.translate-panel`（:648-668）与只读 PBI 卡片。
- 样式：`.replay-original-toggle`（:741-770）26px 胶囊；`.translate-panel`（:935-954）圆角 12px + `--surface-2` 底。

## 4. 踩坑

- 删自动翻译逻辑时残留 `currentTurnId.value = targetTurnId || ''`（:242），`vue-tsc` 报 `error TS2304: Cannot find name 'currentTurnId'`；同批还有 `TS18048: 'message' is possibly 'undefined'`（:303 三处）与 `TS2532`（:529 的 `rows[0].dataset.turnId`）。全部修完 `npm run type-check` exit=0。
- 竖条与按钮联动必须由“滚动 + computed”驱动，不要用 DOM 事件直接改状态，否则滚动中按钮文案会闪。
